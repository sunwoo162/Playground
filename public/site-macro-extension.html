Chrome Extension

사이트별 클릭·입력·스크롤 작업을 원하는 시간에 실행

특정 웹사이트 URL 패턴을 등록하고, 몇 초 간격 또는 매일 12:00 같은 특정 시간에 액션 순서를 실행하는 확장 프로그램입니다. 작업은 사용자가 권한을 허용한 사이트에서만 실행됩니다.

GitHub에서 파일 보기 설치 방법
출석 버튼 누르기 https://example.com/check-in* · 매일 12:00
대시보드 새로고침 클릭 #refresh → 대기 1000ms → 스크롤 500px
최근 로그 success · 액션 3개 실행 완료

예약 방식

작업마다 실행 방식을 선택합니다. 예: 30초 간격, 매일 12:00, 매일 18:30.

액션 종류

클릭, 입력, 대기, 스크롤, 새로고침을 순서대로 조합합니다.

안전 제한

비밀번호 입력, 로그인 폼 자동 입력, 캡차 우회, 숨김 실행은 차단합니다.

설치 방법

  1. GitHub에서 apps/site-macro-extension 폴더를 내려받습니다.
  2. Chrome 주소창에 chrome://extensions를 입력합니다.
  3. 오른쪽 위 개발자 모드를 켭니다.
  4. 압축해제된 확장 프로그램을 로드를 누르고 해당 폴더를 선택합니다.
  5. 확장 아이콘 → 설정 → 작업 추가 → URL 패턴과 액션을 입력합니다.
  6. 사이트 권한 허용을 누른 뒤 작업을 켭니다.
