WebBridge

`C:\Users\user\Documents\webbridge` 폴더에 있는 확장 프로그램입니다. API가 없는 웹사이트도 규칙 기반으로 데이터 추출, 자동화, 웹훅 전송, 저장, 알림까지 연결할 수 있습니다.

설치 방법 보기 웹훅 사용 방법 파일 기능 보기
페이지 정보 → 웹훅extract → transform → http → notify
A사이트 → B사이트 폼 입력extract → open-tab → input → click
목록 스크랩 → 저장page-load → multiple extract → store

데이터 추출

CSS selector로 텍스트, 링크, 속성, 목록을 추출합니다.

자동화

요소 대기, 입력, 클릭, 탭 열기 같은 작업을 단계별로 실행합니다.

연동

웹훅 요청, 클립보드 복사, 저장소 저장, 브라우저 알림을 제공합니다.

쉽게 설치하는 방법

  1. Chrome 주소창에 chrome://extensions를 입력합니다.
  2. 오른쪽 위 개발자 모드를 켭니다.
  3. 압축해제된 확장 프로그램을 로드를 누릅니다.
  4. C:\Users\user\Documents\webbridge 폴더를 선택합니다.
  5. 확장 아이콘을 고정하고 관리 버튼으로 규칙을 만듭니다.
  6. 현재 페이지에서 실행하려면 팝업의 ▶ 버튼 또는 Alt+Shift+B를 사용합니다.

웹훅 사용 방법

웹훅은 WebBridge가 웹페이지에서 뽑은 데이터를 다른 서버로 보내는 방식입니다. 예를 들어 현재 페이지 제목과 URL을 추출해서 Discord, Make, Zapier, 직접 만든 API 서버로 전송할 수 있습니다.

1. 웹훅 URL 준비

  1. Discord라면 채널 설정 → 연동 → 웹후크 만들기에서 URL을 복사합니다.
  2. 직접 만든 서버라면 POST https://your-server.com/webhook 같은 수신 API를 준비합니다.
  3. 테스트용으로는 webhook.site 같은 임시 수신 페이지를 사용할 수 있습니다.

2. WebBridge 규칙 만들기

  1. 확장 아이콘 → 관리를 엽니다.
  2. ＋ 새 규칙을 누릅니다.
  3. 트리거는 처음엔 수동으로 둡니다.
  4. 단계 JSON에 아래 예시를 붙여 넣습니다.
  5. https://hooks.example.com/replace-me 부분을 본인 웹훅 URL로 바꿉니다.
  6. 저장 후 원하는 웹페이지에서 팝업의 ▶ 버튼으로 테스트합니다.
{
  "name": "현재 페이지 정보 웹훅 전송",
  "trigger": { "type": "manual" },
  "steps": [
    {
      "type": "extract",
      "fields": {
        "title": "h1",
        "pageTitle": "title",
        "canonicalUrl": { "selector": "link[rel=canonical]", "attr": "href" }
      }
    },
    {
      "type": "transform",
      "script": "return { title: data.title || data.pageTitle, url: data.canonicalUrl || context.url, sentAt: new Date().toISOString() };"
    },
    {
      "type": "http",
      "url": "https://hooks.example.com/replace-me",
      "method": "POST",
      "headers": { "Content-Type": "application/json" },
      "body": "{{JSON.stringify(data)}}"
    },
    {
      "type": "notify",
      "title": "WebBridge",
      "message": "웹훅 전송 완료: {{data.title}}"
    }
  ]
}

3. Discord 웹훅 예시

Discord 웹훅은 보통 content 또는 embeds 형태를 받습니다. 아래처럼 body를 Discord 형식으로 바꾸면 채널에 메시지가 올라갑니다. 

{
  "type": "http",
  "url": "디스코드_웹훅_URL",
  "method": "POST",
  "headers": { "Content-Type": "application/json" },
  "body": "{ \"content\": \"새 페이지 저장: {{data.title}}\\n{{data.url}}\" }"
}

4. 주의사항

  • 웹훅 URL은 비밀번호처럼 취급하세요. URL을 아는 사람이 메시지를 보낼 수 있습니다.
  • API 키, JWT, 세션 쿠키 같은 민감한 값은 body에 넣지 마세요.
  • 처음에는 반드시 수동 트리거로 테스트한 뒤, 문제 없을 때 page-load나 interval로 바꾸세요.
  • 너무 짧은 간격으로 반복 전송하면 대상 서비스에서 차단될 수 있습니다.
