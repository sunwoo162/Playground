WebBridge

`C:\Users\user\Documents\webbridge` 폴더에 있는 확장 프로그램입니다. API가 없는 웹사이트도 규칙 기반으로 데이터 추출, 자동화, 웹훅 전송, 저장, 알림까지 연결할 수 있습니다.

설치 방법 보기 파일 기능 보기
페이지 정보 → 웹훅extract → transform → http → notify
A사이트 → B사이트 폼 입력extract → open-tab → input → click
목록 스크랩 → 저장page-load → multiple extract → store

데이터 추출

CSS selector로 텍스트, 링크, 속성, 목록을 추출합니다.

자동화

요소 대기, 입력, 클릭, 탭 열기 같은 작업을 단계별로 실행합니다.

연동

웹훅 요청, 클립보드 복사, 저장소 저장, 브라우저 알림을 제공합니다.

쉽게 설치하는 방법

  1. Chrome 주소창에 chrome://extensions를 입력합니다.
  2. 오른쪽 위 개발자 모드를 켭니다.
  3. 압축해제된 확장 프로그램을 로드를 누릅니다.
  4. C:\Users\user\Documents\webbridge 폴더를 선택합니다.
  5. 확장 아이콘을 고정하고 관리 버튼으로 규칙을 만듭니다.
  6. 현재 페이지에서 실행하려면 팝업의 ▶ 버튼 또는 Alt+Shift+B를 사용합니다.
