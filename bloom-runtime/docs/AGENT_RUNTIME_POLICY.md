# Luna Agent Runtime Policy

Owner-only canonical Luna Agent System documentation is maintained in the private `BloomBouquet/.github` repository.

The executable source of truth for runtime behavior remains the code in `bloom-runtime`. In particular:

- senior operating baseline: `bloom-runtime/ts/seniorAgent.ts`
- Luna Visual Style Baseline: `bloom-runtime/ts/lunaVisualStyle.ts`
- headless planning/task injection: `bloom-runtime/ts/headlessBuilderExecutor.ts`

User-facing Luna projects receive the versioned visual baseline automatically. Layout remains product-specific, and explicit Product Owner design/brand/reference direction takes precedence over the default visual style unless safety, accessibility, security, platform, or objective usability requirements require otherwise.

Do not duplicate private Luna operating documentation in this public repository.
