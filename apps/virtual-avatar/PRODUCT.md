# Virtual Avatar

## Product Definition

Virtual Avatar is a browser-based avatar studio for lightweight VTuber-style camera tracking, expression switching, background selection, and optional VRM model loading.

## Market-Ready Baseline

- Users can start and stop camera tracking with clear status feedback.
- Camera permission failures are surfaced in the control panel instead of failing silently.
- Expression, background, rig visibility, camera preview, sensitivity, smoothness, and remote VRM URL settings persist locally.
- Presets can be exported and imported as JSON.
- Local uploaded VRM blob URLs are intentionally excluded from saved presets because they cannot be reused across sessions.
- The default image avatar remains available as a fallback when external VRM loading is unavailable.

## Stack

- React and TypeScript for the app shell and state.
- Vite for local development and production builds.
- MediaDevices, Web Audio, and canvas APIs for camera/audio motion tracking.
- MediaPipe Tasks Vision and Three/VRM modules loaded from CDNs for advanced tracking and VRM rendering.
- Browser localStorage and JSON files for preset portability.

## Required User Setup

- Camera and microphone permission are required for live tracking.
- External CDN access is required for MediaPipe and remote VRM rendering.
- Imported presets must be generated by Virtual Avatar version 1.

## Verification

- `npm run build --prefix apps/virtual-avatar`
- `npm run harness`
