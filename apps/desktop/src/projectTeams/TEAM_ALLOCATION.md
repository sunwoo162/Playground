# Luna Team Allocation

Luna의 다섯 개발 팀(장미, 백합, 튤립, 해바라기, 벚꽃)은 동일한 조직 레벨을 유지합니다.

프로젝트 시작 시 Luna는 현재 `idle` 상태이며 `activeProjectId`가 없는 팀만 후보로 사용합니다. 후보 팀은 다음 순서로 비교합니다.

1. 누적 프로젝트 배정 횟수가 적은 팀
2. 배정 횟수가 같으면 가장 오래 배정되지 않은 팀
3. 모든 조건이 같으면 고정된 팀 catalog 순서

`averageScore`, 임의의 팀 성격, 임의의 전문 분야는 자동 배정 근거로 사용하지 않습니다. 향후 팀별 강점이 사용되더라도 여러 프로젝트의 측정 가능한 실행 결과를 근거로 별도의 정책 변경을 거쳐야 합니다.

각 프로젝트에는 배정 시점의 전략, 기존 배정 횟수, 완료 프로젝트 수, 마지막 배정 시각, 선택 이유를 `teamAllocation` 기록으로 남깁니다. 이 기록은 배정 결정을 감사할 수 있도록 하기 위한 것이며 팀 간 서열을 의미하지 않습니다.
