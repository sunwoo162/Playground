Chrome Extension

사이트별 클릭·입력·스크롤 작업을 원하는 시간에 실행

특정 웹사이트 URL 패턴을 등록하고, 몇 초 간격 또는 매일 12:00 같은 특정 시간에 액션 순서를 실행하는 확장 프로그램입니다. 전용 백그라운드 탭을 켜면 지금 보고 있는 화면과 분리된 탭에서 작업을 계속 실행하고, 대상 구역을 지정하면 그 구역 안에서만 클릭과 입력을 찾습니다.

GitHub에서 파일 보기 설치 방법
출석 버튼 누르기 https://example.com/check-in* · 매일 12:00 · 백그라운드 탭
대시보드 새로고침 클릭 #refresh → 대기 1000ms → 스크롤 500px
최근 로그 success · 액션 3개 실행 완료

예약 방식

작업마다 실행 방식을 선택합니다. 예: 30초 간격, 매일 12:00, 매일 18:30.

액션 종류

클릭, 입력, 대기, 스크롤, 새로고침을 순서대로 조합합니다.

전용 탭 실행

현재 탭을 건드리지 않고 비활성 고정 탭에서 작업을 반복 실행합니다.

설정 항목

  • URL 패턴https://example.com/page*처럼 작업을 실행할 페이지 범위를 지정합니다.
  • 놀이터 주소배포 주소 또는 로컬 주소를 입력합니다. 예: https://playground.https.gsmsv.site
  • 대상 앱놀이터 앱을 고르면 URL이 자동 설정됩니다. 목록에 없으면 직접 앱 경로에 /apps/todo/처럼 입력합니다.
  • 대상 구역전체 화면, 메인, 폼, 상단, 내비게이션 또는 직접 CSS 선택자로 액션 범위를 좁힙니다.
  • 없으면 열 URL조건에 맞는 탭이 없을 때 열 시작 페이지입니다.
  • 전용 백그라운드 탭현재 보는 화면과 별개로 pinned 탭을 만들고 그 탭에서 계속 실행합니다.
  • 실행 방식몇 초 간격 또는 매일 특정 시간을 선택합니다.

액션 작성법

  1. 클릭: 버튼이나 링크의 CSS selector를 입력합니다.
  2. 입력: 입력칸 selector와 입력값을 지정합니다. 비밀번호/로그인 폼은 차단됩니다.
  3. 대기: 다음 액션 전 기다릴 시간을 ms로 지정합니다.
  4. 스크롤: 화면을 아래 또는 위로 이동합니다.
  5. 새로고침: 대상 탭을 다시 불러옵니다.

설치 방법

  1. GitHub에서 apps/site-macro-extension 폴더를 내려받습니다.
  2. Chrome 주소창에 chrome://extensions를 입력합니다.
  3. 오른쪽 위 개발자 모드를 켭니다.
  4. 압축해제된 확장 프로그램을 로드를 누르고 해당 폴더를 선택합니다.
  5. 확장 아이콘 → 설정 → 작업 추가를 누릅니다.
  6. 놀이터 앱에서 실행할 작업이면 놀이터 주소와 대상 앱을 선택합니다. 목록에 없으면 직접 앱 경로를 입력합니다.
  7. 특정 영역에서만 작업하려면 대상 구역을 고르거나 구역 CSS 선택자를 입력합니다.
  8. Enter 같은 키를 반복하려면 액션 타입을 키 입력으로 바꾸고 입력값에 Enter를 적습니다.
  9. 다른 웹사이트 작업이면 URL 패턴과 시작 URL을 직접 입력합니다.
  10. 사이트 권한 허용을 누른 뒤 작업을 켭니다.
  11. 현재 화면과 분리해서 계속 돌릴 작업은 전용 백그라운드 탭에서 계속 실행을 켭니다.

주의할 점

  • 브라우저가 완전히 종료되었거나 컴퓨터가 절전 상태이면 예약 작업은 실행되지 않습니다.
  • 사이트 로그인이 만료되면 사용자가 직접 다시 로그인해야 합니다.
  • 캡차 우회, 보안 우회, 숨김 실행, 비밀번호 자동 입력은 지원하지 않습니다.
  • 작업은 사용자가 직접 권한을 허용한 사이트에서만 실행됩니다.
