# 사이트 액션 매크로 확장 프로그램

사용자가 지정한 웹사이트에서 CSS selector 기반 액션을 간격 또는 특정 시간에 실행하는 Chrome MV3 확장 프로그램입니다.

## 기능

- URL 패턴별 작업 등록
- 놀이터 앱 프리셋 선택 시 URL 패턴 자동 설정
- 작업별 대상 구역 지정 후 그 구역 안에서만 클릭/입력 실행
- 몇 초 간격 실행
- 매일 특정 시간 실행
- 클릭, 입력, 키 입력, 대기, 스크롤, 새로고침 액션
- 탭이 없으면 지정 URL을 새 탭으로 열기
- 현재 보고 있는 탭과 분리된 전용 백그라운드 탭에서 반복 실행
- 작업별 사이트 권한 요청
- 최근 실행 로그 표시

## 안전 제한

- 최소 반복 간격은 5초입니다.
- 작업당 액션은 최대 20개입니다.
- 비밀번호 입력칸 자동 입력은 차단합니다.
- 로그인 폼 자동 입력은 차단합니다.
- 캡차 우회, 보안 우회, 숨김 실행 기능은 제공하지 않습니다.
- 사이트 권한을 사용자가 직접 허용한 origin에서만 실행합니다.
- 브라우저가 완전히 종료되었거나 컴퓨터가 절전 상태이면 실행되지 않습니다.
- 사이트 로그인 세션이 만료되면 사용자가 직접 다시 로그인해야 합니다.

## 사용 방법

1. Chrome 확장 프로그램 페이지에서 `개발자 모드`를 켭니다.
2. `압축해제된 확장 프로그램을 로드`로 `apps/site-macro-extension` 폴더를 선택합니다.
3. 확장 아이콘을 누르고 `설정`을 엽니다.
4. 작업을 추가합니다.
5. 놀이터 앱에서 실행할 작업이면 `놀이터 주소`와 `대상 앱`을 선택합니다. 목록에 없으면 `직접 앱 경로`에 `/apps/.../`를 입력합니다.
6. 필요한 경우 `대상 구역`을 고르거나 `구역 CSS 선택자`를 직접 입력합니다.
7. 일반 웹사이트 작업이면 URL 패턴을 `https://example.com/*`처럼 직접 입력합니다.
8. `사이트 권한 허용`을 누릅니다.
9. 앱을 선택하면 `탭이 없으면 새 탭으로 열기`와 `전용 백그라운드 탭에서 계속 실행`이 자동으로 켜집니다.
10. 실행 방식과 액션을 지정한 뒤 `사용`을 켭니다.

## 액션 예시

```txt
URL 패턴: https://example.com/dashboard*
실행 방식: 매일 12:00
액션:
1. 클릭 / selector: #refresh
2. 대기 / ms: 1000
3. 클릭 / selector: .submit-button
```

```txt
실행 방식: 10초 간격
액션:
1. 키 입력 / 입력값: Enter
```

CSS selector는 브라우저 개발자도구에서 원하는 요소를 우클릭하고 `Copy selector`로 얻을 수 있습니다.
