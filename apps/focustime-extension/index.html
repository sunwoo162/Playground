Install

설치 순서

  1. 01

    릴리즈 파일 다운로드

    FocusTime.zip을 받은 뒤 압축을 해제합니다.

  2. 02

    Chrome 확장 로드

    chrome://extensions에서 개발자 모드를 켜고, 압축 해제된 폴더를 로드합니다.

  3. 03

    앱 추적기 실행

    앱 사용 시간까지 보려면 Start-FocusTimeTracker.bat을 실행합니다.

웹은 확장 프로그램이 기록합니다

확장 프로그램이 도메인별 사용 시간, 오늘 한도, 차단 상태를 브라우저 안에서 관리합니다.

앱은 로컬 트래커가 기록합니다

FocusTimeTracker가 실행 중인 Windows 앱 시간을 별도로 쌓고, 차단 앱은 실행되면 종료합니다.

데이터는 기기 기준입니다

설치한 사용자의 브라우저와 PC에서 생성된 값이 각자 FocusTime 대시보드에 표시됩니다.
