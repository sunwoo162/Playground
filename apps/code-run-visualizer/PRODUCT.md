# Code Run Visualizer

## Product Definition

Code Run Visualizer is an educational coding tool that shows how JavaScript, Python, and Java-like examples move through compile and execution phases. It is built for learners who need line-by-line feedback, algorithm animation, memory snapshots, output tracing, and lightweight editor assistance.

## Market-Ready Baseline

- Users can switch language templates and algorithm examples without losing the current browser workspace.
- The app validates code with visible compile/runtime status before animation.
- Sorting and search examples include step controls, playback speed, random input generation, and visual state tracking.
- The current workspace is persisted locally and can be exported/imported as JSON for class sharing or recovery.
- Imported files are validated by app id and backup version before replacing the workspace.

## Stack

- React and TypeScript for the interactive app.
- Vite for local development and production builds.
- Browser localStorage for draft persistence.
- JSON file import/export for portable workspaces.

## Required User Setup

- No account is required for the core visualizer.
- Imported workspace files must be generated by Code Run Visualizer version 1.

## Verification

- `pnpm --filter ./apps/code-run-visualizer run build`
- `pnpm run harness`
