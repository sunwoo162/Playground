# Idea Mixer

## Product Definition

Idea Mixer is a creativity tool that pairs two random words and helps users turn forced combinations into product, app, content, or service ideas.

## Market-Ready Baseline

- Users can redraw either word independently or randomize both words together.
- Guided prompts and example angles help users move from random words to concrete ideas.
- Saved ideas persist locally in the browser.
- The idea board can be exported and imported as JSON for backup, sharing, or migration.
- Imported notes are validated by app id/version and regenerated with local ids.

## Stack

- React and TypeScript for the app interface.
- Vite for local development and production builds.
- Browser localStorage for saved ideas.
- JSON import/export for portable idea boards.

## Required User Setup

- No account is required.
- Browser localStorage must be available for saved idea persistence.
- Imported board files must be generated by Idea Mixer version 1.

## Verification

- `pnpm --filter ./apps/idea-mixer run build`
- `pnpm run harness`
