Native Messaging

사이트 액션 매크로를 Windows 앱과 연결

Chrome 확장이 직접 제어하지 못하는 Windows 앱에 키 입력, 텍스트 입력, 좌표 클릭을 전달하는 로컬 브리지입니다.

설치

  1. .NET SDK 8 이상을 설치합니다.
  2. apps\site-macro-native-bridge\build.ps1을 실행합니다.
  3. chrome://extensions에서 사이트 액션 매크로 확장 ID를 복사합니다.
  4. install-chrome-host.ps1 -ExtensionId 확장ID를 실행합니다.

지원 액션

  • 키 입력: Enter, Tab, Escape 등
  • 입력: 활성 앱 창에 텍스트 전송
  • Windows 좌표 클릭: 화면 x/y 좌표 클릭
  • 대기: 지정 ms만큼 대기

명령

apps\site-macro-native-bridge\build.ps1
apps\site-macro-native-bridge\install-chrome-host.ps1 -ExtensionId YOUR_EXTENSION_ID
