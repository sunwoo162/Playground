WebBridge Guide

이 폴더의 기능을 바로 이해하고 쓰는 가이드

WebBridge는 웹페이지에서 데이터를 뽑고, 변환하고, 다른 웹훅이나 사이트로 보내는 작업을 규칙으로 저장하는 확장 프로그램입니다. 아래에서 원하는 목적을 선택하면 규칙 JSON 예시를 바로 만들 수 있습니다.

1. 무엇을 하나?

  • 현재 페이지의 제목, 링크, 목록 같은 데이터를 추출합니다.
  • 추출한 데이터를 JavaScript로 가공합니다.
  • 웹훅, 다른 사이트 폼, 클립보드, 알림으로 연결합니다.

2. 언제 실행하나?

  • 팝업 버튼으로 수동 실행
  • 페이지 로드 시 자동 실행
  • 몇 분 간격으로 주기 실행
  • Alt+Shift+B 단축키 실행

3. 어디서 설정하나?

  • popup/popup.html: 빠른 실행
  • options/options.html: 규칙 관리
  • examples/examples.json: 예제 규칙

파일별 기능

        

          
            

              파일
              기능
              사용자가 보는 위치
            

          
          
            

              manifest.json
              확장 이름, 권한, popup/options/background/content script 연결을 정의합니다.
              Chrome 확장 프로그램 설치 정보
            

            

              background.js
              규칙 실행, 탭 제어, 알람, 알림, 웹훅 요청 같은 백그라운드 작업을 담당합니다.
              사용자에게 직접 보이지 않는 실행 엔진
            

            

              content.js
              실제 웹페이지 DOM에서 selector로 요소를 찾고 추출/클릭/입력을 수행합니다.
              규칙이 실행되는 웹페이지 내부
            

            

              popup/*
              확장 아이콘을 눌렀을 때 규칙 검색, 켜기/끄기, 현재 탭 실행을 제공합니다.
              브라우저 확장 팝업
            

            

              options/*
              규칙 생성, 수정, 복제, 삭제와 단계 JSON 편집 화면을 제공합니다.
              규칙 관리 화면
            

            

              examples/examples.json
              처음 규칙을 만들 때 참고할 수 있는 샘플 규칙 모음입니다.
