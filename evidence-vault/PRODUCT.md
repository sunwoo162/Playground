# 증빙함 (Evidence Vault)

## 제품 한 줄

구매·구독·렌탈·환불 과정에서 나중에 필요할 수 있는 사실과 파일을 평소부터 개인적으로 정리하고, 중요한 날짜를 놓치지 않도록 보여주는 증빙 관리 웹앱입니다.

## 첫 완전한 흐름

1. 꽃다발 계정으로 로그인합니다.
2. 구매/계약 하나를 `증빙함`으로 등록합니다.
3. 사용자가 알고 있는 반품·갱신·보증·약정 날짜를 직접 기록합니다.
4. 구매/배송/하자/환불 요청/업체 답변 이벤트와 파일을 시간순으로 붙입니다.
5. 필요한 경우 `분쟁 준비 모드`에서 관련 자료를 골라 중립적인 증빙 패킷으로 내보냅니다.

## 제품 경계

이 서비스는 개별 사건의 법률 판단, 법률상담, 법률대리, 승소/환불 가능성 예측을 제공하지 않습니다. 날짜도 법적 효력을 자동 판단하지 않고 `사용자가 ~로 기록한 날짜`처럼 출처를 드러냅니다.

## 데이터

서버 저장이 필요한 데이터: 꽃다발 identity subject와 앱 프로필, 앱 세션, 증빙함 항목, 사용자 입력 기한, 타임라인 이벤트, 비공개 파일 메타데이터/무결성 확인값, 분쟁 준비 케이스, 내보내기 기록, 삭제 작업 상태.

## 로컬 실행

```bash
cp .env.example .env.local
pnpm install
pnpm dev
```

데이터베이스와 실제 꽃다발 OAuth 연동이 붙기 전에는 랜딩/health shell만 확인할 수 있습니다. 앱 자체 이메일/비밀번호 로그인은 만들지 않습니다.

## Production blockers

- 꽃다발 OAuth client 등록과 정확한 production redirect URI
- PostgreSQL production database
- 한국 리전 우선의 private S3-compatible bucket 및 credentials
- `SESSION_SECRET` 안전한 주입
- 개인정보처리방침/이용약관 확정 및 출시 직전 법무·개인정보 최종 검토
- production domain/TLS
